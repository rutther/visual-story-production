# 可合并到项目指令的片段

使用本项目所附 visual-story-production 方法包；先读取其 SKILL.md，按问题加载 references。保留现有项目规则与当前用户要求。每段实质性动画制作前实际查看参考、保存并检查首中尾分镜；随后实现并观察真实运动。内容、视觉、时钟、素材身份和可编辑性分别验证。

在项目 STATE.md 记录当前目标、有效约束、实际版本、已看范围、已知问题、活跃作业和下一动作。新会话先验证现状，再继续。未获本项目导出授权不生成视频；发布、上传、付费依当前授权。

此文件为可选适配片段，不能覆盖更高层指令，不要求目标harness必须识别某一文件名。
