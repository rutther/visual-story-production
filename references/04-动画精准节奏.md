# 动画与精准节奏

> 阶段规则：本章中的编码、MP4、成片检查均以当前交付范围和用户授权为前提。Web预览阶段不要求生成视频；先完成可编辑工程的实际检查。历史案例中的数量、参数和角色不是新项目默认值。

## 1. 给每个动作一个信息目的

动作至少完成一件事：吸引到关键处、解释状态变化、保留对象连续性、展示过程、表达规模或控制情绪。删掉动作后如果理解和表达完全不受影响，它可能只是装饰；是否保留仍要看作品用途。

| 语义 | 动作方式 | 必查端点 |
|---|---|---|
| 出现/发现 | 遮罩展开、局部强调 | 最终内容完整 |
| 从A到B | 主体连续移动、路径或镜头跟随 | 同一主体身份和空间连续 |
| 加入/离开 | 联系建立或退出 | 连接对应正确对象 |
| 冲突/阻断 | 断开、阻挡、分离 | 不把正常合作画成断线 |
| 组成/分解 | 层级展开、分件对应 | 组件关系和数量准确 |
| 放大细节 | 镜头推进、上下文到局部 | 目标细节来自原素材 |
| 先后/因果 | 顺序触发、结果随后出现 | 不让结果抢在原因前形成误解 |
| 对比 | 对齐、切换、共用尺度 | 比较维度一致 |

## 2. 精准控制节奏的四个时钟

声音时钟：实际语句和停顿；已有音频是依据，TTS计划时长不是依据。

意义时钟：信息何时被说到，何时需要揭示。

阅读时钟：观众理解字、图表和细节需要停留多久。

动作时钟：完成运动和到位所需时间。

节奏要协调四者。讲到关键名词时图形已经可辨认，讲到结果时图形变化到位，随后保留阅读时间。不要为了动画播完让观众等待下一句，也不要在复杂图形刚出现时就切走。

## 3. 声音和字幕对齐

已有口播：根据实际声音或可靠转录边界定位；切点在语义和呼吸处，不切掉尾音。

新配音：先确认允许的文本修改范围，合成后用实际音频和词边界修正时长。中文人名、外语、型号、年份、单位和多音字单独检查。

字幕不是按总字数平均分时间。优先按词/短句边界，保护关键串和标点；反复出现的词要用逐步游标匹配，不能每次从段落开头查第一次出现。

## 4. 怎样诊断“太慢”或“太快”

太慢候选：句间合成尾部空白过长；动画先等待再出现；段落画面没有新信息；同一照片重复停留；声画切换被工具加载拖慢。

太快候选：专有名词连续堆积；图表刚出现就切走；字幕三行以上；动作和旁白同时争抢注意；结果在观众辨认主体前发生。

处理先找到原因，再调对应参数。语速、尾部空白、镜头长度、动作时间、阅读停留是不同控制项。不能用一个全局倍速解决所有问题。

## 5. 参数不是固定教条

常规小变化通常用较短时间；长距离空间移动、过程或情绪段需要更长时间。可用0.2—0.5秒作为短状态变化的起始试验，0.5—1秒作为明显布局/焦点转移的试验，再按内容和实际播放调整。

缓动表达到位、惯性或连续运动。新闻关系图不宜无故弹跳；角色动画可以按重量使用预备动作和后续动作；工艺视频要服从机械动作，不能随意拉伸物体。

## 6. 精准不等于机械

先编排主动作，再安排次要动作。相邻对象错峰可以建立阅读顺序，但不用固定间隔铺每个场景。场景内应有进入、变化、稳定、离开的阶段；复杂度越高，辅助运动越克制。

边界连续性：检查前一镜头最后一状态、切点、新镜头初态和第一次文字出现。硬切、叠化、擦除、匹配移动都可以使用，只要服务内容且没有残影和跳变。

## 7. 程序化动画的确定性

用时间/帧计算状态：`state = render(content, localTime)`。随机值若确需使用，固定种子并保存。拖到同一时间、从头播放和导出应一致。

不要用浏览器墙钟、未同步的CSS动画或异步随机状态决定成片。响应式页面的动画可以用真实交互时钟；导出时需显式转换为可控制的时间轴。

## 8. 动态与可访问性

网页控制需有暂停、定位和错误恢复；交互带来的非必要大幅运动可依系统减少动态偏好减弱。减少运动仍要保留内容、状态和反馈。成片的艺术动作与网页控件的交互动作分别配置。
