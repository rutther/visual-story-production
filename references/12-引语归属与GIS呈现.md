# 引语归属与 GIS 呈现

> 阶段规则：本章中的编码、MP4、成片检查均以当前交付范围和用户授权为前提。Web预览阶段不要求生成视频；先完成可编辑工程的实际检查。历史案例中的数量、参数和角色不是新项目默认值。

## 把归属变成生产规则

先抽取全文里的引号、引述动词与上下文，再逐条判断：直接引语、间接转述、术语／绰号／行动名称、跨段未闭合的引语。不能用“有引号就套一个人物头像”的正则替代内容理解。人名中带引号的昵称、武器名称、作者的比喻都不等于有人发言。

制作一份独立的 cue 清单：场景 ID、原文字符起止、逐字文本、身份 ID、类型、相对时间、页序。口播与音频时轴是只读输入。文本从原文字符范围直接截取；不要先改写句子再声称逐字一致。

每个明确归属的发言统一呈现真实头像或所属机构的真实标志、发言人姓名、文中身份与话语。身份列和内容列一起出现，不能先显示一句话，几秒后才补名字。没有真实照片的普通受访者使用明显的中性人物图标和真实姓名，不能用素材库中另一个人的脸或生成一个写实人像。匿名来源用文中的准确描述，不把“消息人士”替换为某位知名政治人物。

无法确定的归属不得自动猜。询问必要的一句；用户明确要求无法找到的归属按作者讲述处理时，记录这项授权，并仅用于相应未明句，不把已经明确归属的内容改成作者发言。这样的授权是项目约定，不能默认套到别的项目。

短引语可以整体展示；长引语按标点、词边界与可读行数分页。每一页保留身份，并在实际说到对应内容时切页。跨段引语沿用身份和上下文。不能仅显示第一句、删掉后半段或用省略号替代。间接转述保留原文已有引号，整段不能额外套引号，让作者的连接语变成发言人的逐字引语。

## 身份素材研究与检查

优先人物所在机构的资料页、政府肖像、本人资料页和可核对许可证的 Wikimedia Commons 文件页。姓名相近不是同一个人：检查全名、单位、职务与实际照片。媒体文章的主图常是事件画面或另一位领袖，不能把页面标题当成人像身份凭据。实践中曾发现采访页面的主图是群众举着另一位人物的海报，因此排除该主图，改用已核对的组织标识。

每项保存下载地址、资料页、原始文件、哈希、作者／许可证说明、派生文件与是否入选。官方网页照片不自动等于开放许可；标志的识别用途和商标权区别于照片的版权。原有素材继续按用户确认的素材库关系处理，不能在画面中夹带来源猜测或审稿评论。

## GIS 必须来自地理数据

地图应解释口播的空间关系。海岸／国界用有来源的矢量数据；山地用真实 DEM；航路用真实航路或明确性质的水域连通示意。不能用装饰曲线冒充战线或部队进攻路径。精度与用途一致：区域背景不需要把城市点说成机场、炼厂或军事设施的精确坐标。

Mapzen Terrain Tiles 的 Terrarium PNG 是高程编码，不是普通照片。按官方格式 `R*256 + G + B/256 - 32768` 解码成米，记录瓦片 zoom/x/y、范围、投影与下载哈希。瓦片是 Web Mercator，叠加定位点必须使用同一投影；不能把纬度线性拉伸后仍声称与地形精确对齐。

离线合并瓦片后计算坡度、阴影与高程色带。等高线必须从 DEM 数值生成。图例写真实单位；若做垂直夸张，必须明确倍数。数据来自混合供应商时保存官方 attribution 文档，按实际区域使用的数据来源署名，不能把 AWS 托管服务说成地形采集机构。

地形数据技术入口（使用时核对当前版本与区域）：

- [AWS Terrain Tiles 数据集](https://registry.opendata.aws/terrain-tiles/)
- [Terrarium 官方格式](https://github.com/tilezen/joerd/blob/master/docs/formats.md)
- [供应商与署名规则](https://github.com/tilezen/joerd/blob/master/docs/attribution.md)

动画用叙述中的地名／地形词触发：区域地图定位 → 地形淡入 → 等高线展开 → 小幅地理视窗推进。照片、文字与地图可以采用不同的运动语法；不把每段都做成同一种下滑字幕。离线资源让预览和成片不依赖地图服务实时联网。

## 实际验收

逐条核查引语原文字符、身份、起止时间、分页覆盖和人物／机构图片加载。每个状态生成真实渲染帧，检查身份是否与内容同时可见、文字是否溢出、字幕是否遮挡、前后没有引语时能否恢复原画面。特别检查 `classList.toggle` 的 force 参数必须是布尔值；传 undefined 会产生意外切换，导致普通地图被空白引语层盖住。

GIS 分别检查原始瓦片、派生底图、定位投影、实际页面、导出帧和最终编码视频。主预览更新后，旧 MP4 不会自动变化。源代码通过、DOM 文本正确、PNG 生成和 MP4 编码各是独立证据，不能互相替代。
