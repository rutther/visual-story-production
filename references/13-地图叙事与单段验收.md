# 地图叙事与单段验收

> 阶段规则：本章中的编码、MP4、成片检查均以当前交付范围和用户授权为前提。Web预览阶段不要求生成视频；先完成可编辑工程的实际检查。历史案例中的数量、参数和角色不是新项目默认值。

## 从观众需要知道什么开始

地理画面要回答四个问题：在什么地区、地形为什么重要、谁在行动、向哪里变化。只画海岸线、几个城市点和一条字幕，常常不能完成这个任务。尤其是山口、山脉、峡谷、海峡、机场等内容，需要与其性质对应的数据层。

区域定位和局部过程承担不同职责。先让观众看到国家／海域关系，再推进到具体区域；局部放大后保留区域小图和当前视窗范围，避免观众失去尺度。地名、指北针和比例尺是信息，比例尺必须按当前投影和缩放计算。不能把地图放大了而仍保留上一个视窗的公里数。

## 角色记忆要持续

复杂政治或军事叙事不能假设观众一直记得前几分钟出现的角色。使用稳定的短身份提示，例如组织标识＋阵营名称＋当前角色。提示应来自文案前后已明确的关系，不能凭画面风格猜测阵营。两个同属一方但彼此不协调的部队，应该让观众同时看到共同阵营和不同部队，而不是让两个框看起来像敌对国家。

主图负责空间与变化；角色栏负责身份；过程状态负责当前动词；字幕负责准确口播。四者不必把同一整句重复四次。引语进入时保留必要空间上下文，同时让发言人身份与话语的归属清楚。

## 地形、地点和行动精度分开

DEM 可精确提供地表高程，但不证明某支部队的位置。地名数据库可能提供村镇或地区中心，也不一定是山口鞍部的测量点。保存坐标来源与精度说明；在使用地区中心时用区域定位视觉，不把它升级成具体哨所、壕沟或攻击起点。

有来源的“向西朝海岸推进”可以用方向箭头表达。宽方向箭头与真实道路轨迹、战线边界是不同语法：不要画多段弯曲线、道路节点和行军车辆后暗示拥有未提供的 GPS 路线。具体行动过程忠实依据讲述，地理资料仅补足空间背景。

真实高程可以解码、拼接后生成坡度阴影和高程色带。阴影增强不等于把山体高度夸大；若改变三维高度必须记录倍数。所有光照、插值、坐标变换和图层裁切都属于可重复的制作参数。

## 按语义绑定动作

用实际词级时间找出“分别把守、互不信任、攻占、向西推进”等触发点。镜头先说明位置，随后揭示问题，再改变行动方向。动画库负责缓动和时间轴，不能负责替代文案理解。

时间轴应暂停并接受绝对时间定位；播放、直接跳转、倒退和离线导出使用同一状态。不要把事后赋予的世界状态留在地图对象上，使倒退到早期仍显示后来的攻势。新的镜头进入时销毁前一个镜头的时间轴，重建相应初态。

## 网页预览与影片输出分别检查

网页中正常显示的 SVG `<image href="相对路径">`，放进独立 SVG／foreignObject 导出时可能失去原路径上下文。打包 HTML `<img>` 以外，还要枚举 SVG `<image>`，把资源转为内嵌数据地址，再检查实际 PNG；不能看到网页地形正常就假设电影也有地形。

在当前授权的预览载体中检查单段原尺寸画面和相应音频；只有导出已获授权时才编码单段影片。检查完整段落的开头、区域推进、地形切换、关键行动、结尾和相邻恢复状态，再纳入全片。单段通过不代表全片通过。

检查同一时间先正向定位再从后面倒回，比较文字、地理视窗、箭头长度、身份和实际像素。几何和标签一致但图片仍有像素差异时，要定位差异区域和幅度，再排查浮点坐标、纹理缩放或首次解码。不要直接把“文件哈希不一样”当成全幅构图不同，也不要只看 DOM 一致就忽略实际图像差异。

## 一段一验与有限轮次

用户要求逐项推进时，每次选择一个明确段落：记录问题 → 查数据与参考 → 实现 → 渲染 → 查看 → 修正 → 同段复验。其他段落仍在任务范围，但不要同时改动所有段落，让问题来源不可追踪。

按问题安排修正轮次，以下是可选分工而非固定轮数或停止条件：第一轮解决空间与信息结构；第二轮解决动作与语义时间；第三轮解决遮挡、资源及导出一致性；第四轮用于实际发现的剩余问题。每轮保留观察证据；轮次数量不能充当质量证明，不能为了凑轮数无目的地换颜色。

## 可核对的技术入口

- [GSAP Timeline](https://gsap.com/docs/v3/GSAP/Timeline/)：暂停时间轴、直接定位和时间组合。
- [D3 地理投影](https://d3js.org/d3-geo/projection)：坐标、缩放与投影。
- [Terrain Tiles 官方数据](https://registry.opendata.aws/terrain-tiles/)：真实高程输入与数据说明。
- [Terrarium 格式](https://github.com/tilezen/joerd/blob/master/docs/formats.md)：RGB 解码规则。

这些是当前可用技术入口，不代表其他渲染器不能实现同样的语义。跨项目迁移时保留方法，重新确认内容、来源、画幅、品牌和导出条件。
