# 观众反馈与评价

## 1. 先确认“好”指什么

视觉好看、理解容易、节奏紧凑、信息可靠、品牌一致、操作可用和完成委托是不同维度。某一项高分不能抵消核心任务失败。

观众也不是同一种人：手机静音刷短片的人、听专家分析的人、学习操作的人、采购设备的人、欣赏艺术的人，对细节和节奏的需求不同。先按委托和实际反馈判断；没有数据时，把推断写成假设。

## 2. 用具体反馈识别原因

| 反馈 | 先看什么 | 不应直接做什么 |
|---|---|---|
| 太慢 | 语句空白、信息增长、阅读停留、动画等待 | 给整片统一倍速 |
| 太单一 | 相邻骨架、素材内容、变化语义 | 多加随机转场 |
| 地图太小 | 目标地点、窗口面积、标签大小、无关空白 | 只放大底图色块 |
| 看不清 | 实际手机尺寸、字号、对比、裁切、停留 | 只增加锐化或阴影 |
| 信息太少 | 缺失上下文、比较、单位、过程和结果 | 塞满小字和英文标签 |
| 太乱 | 同时运动的对象、阅读焦点、层级和颜色职责 | 统一全部缩小 |
| 不高级 | 比例、留白、素材质感、对齐、动作到位 | 套用霓虹、颗粒或玻璃效果 |
| 不是我想表达的 | 讲述权限、素材匹配、图形语义 | 再写一篇新口播解释自己 |

## 3. 原型比较

比较要控制变量：同一实际内容、相同画幅和素材条件，分别改变骨架或某个明确动作。观察哪一方案更易辨认主体、比较关系、读取数据或保留情绪。

一次只为一个有实质差异的选择制作候选。用户已选视觉世界时，比较相应问题的可行解法，别重新抛五套全新品牌让用户重复选。

## 4. 人的检查任务

如果有真实观众反馈，可以问他们完成具体任务：指出当前地点、说出前后变化、找到关键型号、说明下一步操作。完成任务的观察比“你喜欢吗”的单句评价更有诊断价值。

审美偏好仍可直接问，但记录受众、设备、版本和展示范围；不要把一个人的偏好推广为所有人喜欢。

没有真实测试条件时，代理按任务和当前画面做检查，诚实称为代理观察或假设。不能编造“用户满意度”“A/B提升”或真人接受率。

## 5. 评价顺序

一般先看内容与任务是否准确，再看主体/骨架与关系，再看可读性和动作节奏，最后看色彩、字体细节和质感。这个顺序用于诊断，不是普遍心理学权重公式。

已经明确的偏好直接进入约束。用户指出的是某个蓝色编号，就先修那个编号及相关统一强调色，不自行改地图底色。精准理解反馈本身就是设计工作的一部分。

## 6. 方法的验证范围

记录每个结论适用于什么：任务类型、内容密度、屏幕、素材和工具。比如“会议照片改横向窗口后两侧人物保留”是可观察结果；“横向窗口所有视频都更高级”是没有依据的推广。

当新项目与验证范围不同，先做小规模真实内容试验，再决定是否迁移。这是复用方法，不是机械复用模板。
