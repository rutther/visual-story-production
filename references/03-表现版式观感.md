# 表现方式、版式与观感

## 1. 选择表现方式的决策树

- 观众需要看到动作本身：优先真实视频，保留关键动作的起止和结果。
- 观众需要辨认人物、对象、环境：优先照片或视频；文字指向主体，不遮主体。
- 观众需要比较位置和范围：地图或空间示意。
- 观众需要比较数值：有单位和明确尺度的图表；单一重要数值可独立呈现。
- 观众需要理解先后：时间线或步骤；保留前后关系。
- 观众需要理解联系或变化：关系图、路径、状态迁移。
- 观众需要理解组成与过程：分解、层级、机制演示、逐步展开。
- 观众需要抓住观点和经历：引语、关键词、人物与细节。

一个段落可以换两种表现，但每次切换应增加理解。地图不应因为“有地名”就出现；引语卡不应因为缺图就无限铺满全片。

## 2. 设计骨架先于颜色

先确定主信息、阅读顺序、空间比例和前后景关系，再定颜色、字体、纹理和细节。

常用骨架及条件：

| 骨架 | 适用 | 风险 |
|---|---|---|
| 满幅照片叠字 | 现场、情绪、视觉主体强 | 对比不足、文字遮脸、过度暗化 |
| 图片窗口＋编辑大字 | 多主体、宽画幅、理性解释 | 图片太小、文字重复 |
| 文字主导＋小图/细节 | 概念或关键判断 | 变成朗读PPT、缺少视觉推进 |
| 地图为主＋注释 | 空间关系、路线、区域比较 | 地理精度、标签拥挤、假航线 |
| 主数值＋相关信息 | 规模、阶段或结果 | 无分母、假刻度、单位混乱 |
| 主体节点＋联系 | 合作、冲突、归属与转向 | 关系箭头歧义、连线悬空 |
| 双图/分屏 | 前后、细节与环境、实际比较 | 同图重复、未对齐比较维度 |
| 过程展开/分解图 | 工艺、机构、教学 | 示意冒充实拍、细节超过阅读能力 |

## 3. 用户偏好怎样成为可执行标准

把用户评价绑定具体元素和状态。用户说“蓝色不够蓝”，先确认说的是编号、地图、底色还是全局强调；不能连带重做全部画面。用户给出色值时按该值实施，复查小标题、线、数字和进度是否遗漏。

用户说“慢”，先检查语速、句间空白、镜头停留、动画等待和信息增长；不能直接加速所有动作。用户说“单一”，先检查骨架、素材场景和动作语义，再改变类型；只换转场不能解决。

用户说“丑”，用参考和当前画面比较比例、空白、字重、主体、关系和节奏，找到可修改的因素。不要用“高级”自评分替代实际观察。

## 4. 信息层级

主要视觉信息、次要补充、字幕和全局信息各自承担工作。字号和位置表示层级，色彩承担强调或语义，不应同时用所有变量突出所有信息。

密度取决于目标设备和内容复杂度。大屏演讲允许更少文字；静音社媒需要自足的字幕和上下文；技术演示需要可见的动作细节；正式数据报告需要单位和定义。

多种信息可以充实画面，但主焦点同时通常只保留一个。让图形稳定后给阅读时间，不让主体、图表、字幕和背景一直同时运动。

## 5. 中文、数字和多语言

中文按方块字理解，检查实际字形、字体覆盖、行高和行首标点。避免负字距。保护数字、缩写、型号和单位，不拆开关键串。长标题不要只用缩小字号解决，先看能否合理换行或调整区域。

不同语言长度不一样，翻译版需要真实文案重新检查，不只替换字符串。阿拉伯文方向、数字方向和字体覆盖需要额外检查。字幕安全区域按平台UI和实际标准配置，不能凭经验固定一套。

## 6. 图片处理

裁切和调色服务内容。保留主体眼睛、手部动作、关键设备、铭牌或操作反馈。黑白、高反差、双色调会改变素材气质和信息，应说明理由；新闻/科学/产品色彩本身有意义时，处理不能改变该信息。

为文字对比添加局部渐变或不透明底条时，检查最亮和最复杂的画面。不能以“有阴影”就判可读。手机预览时需看实际缩放后的字号和照片细节。

## 7. 常见“高级感”误区

- 加很多小字、英文标签、网格和装饰图标，实际没有新信息。
- 滤镜、颗粒、霓虹、玻璃和阴影掩盖不合理骨架。
- 同一淡入、同一字号、同一上下分区铺全片。
- 用随机动画制造变化，却破坏焦点和语义。
- 图片用得大但裁掉重要对象，或照片很漂亮却与讲述无关。

更可靠的质量来自明确比例、真实素材、阅读秩序、连续关系、精准端点和适当的变化。华丽效果只有在内容和视觉世界支持时才采用。
