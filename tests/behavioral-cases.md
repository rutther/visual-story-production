# 迁移后的行为检查题

这些是可重复使用的检查场景和判据，不是已执行的独立模型评测。先给目标代理任务，再看其实际决定和产物；复述规则不算通过。无需购买外部课程或提供原视频。

| 输入场景 | 应观察到的决定/产物 | 失败表现 | 方法入口 |
|---|---|---|---|
| 只有普通harness，没有技能发现 | 从START-HERE读取SKILL及相关章节，建立状态文件，识别现有工具 | 要求用户安装同名专用插件才能开始 | PORTABILITY、17 |
| 8500字定稿，旧需求160秒，后来要求保留全文 | 保留正文；用实际声音或语速估计重排时长，记录冲突依据 | 自行缩写正文、字幕替代原话 | 01、11、19 |
| 指出一个编号的蓝色不对，给出色值 | 修对应色彩变量和相关元素，查看实际渲染 | 全局改地图、重做全部分镜 | 09、15 |
| 地图上要呈现山口，但只知道大致区域 | 找可靠地形与地点来源，区分精确点/区域；先画三帧 | 用随手画的山形、精确箭头冒充实地路线 | 12、13、15 |
| 两段连续原话来自同一个机构 | 身份连续，内容随口播更替；检查间隔和结束状态 | 机构logo反复飞入、上一句停留到下一人发言 | 10、12、14 |
| 用户要紧张节奏、中立观感 | 用节奏和焦点变化；照片不因对象身份统一暗化 | 用污渍、红光、怪物化表现替内容判断 | 16 |
| 只能取得截图，不能连续看运动或听音 | 完成排版/时间结构检查，具体标记运动/听音缺口 | 写normalSpeed=true后宣布动画已验收 | 17、18 |
| 暂时只验收Web工程 | 可暂停、拖动、重进、修改；不自动编码 | 每改一个镜头就输出MP4 | 19、SKILL |
| 过滤产品教学演示 | 展示结构与流动、前后状态；核对实际参数 | 照搬新闻头像、战区地图和国旗 | examples/跨题材示例 |
| 用户要求完成完整作品 | 检查每个指定素材、全篇覆盖和实际交付范围 | 仅做代表段就标完成 | 01、06、18 |
| 同一时点倒回、重进 | 主体、标签、裁切与连线恢复同一状态 | 依赖上一镜头、墙钟或未来残留 | 08、19 |
| 已记录的任务handle超时 | 查询同一活跃作业及产物，区分超时与终止 | 因一次等待超时重复启动长任务 | 07、08、17 |

每项记录目标环境、版本、输入、实际动作、证据和差距。需要改善时修改对应方法源文件，再重建合并手册。不要用通过这些题宣称所有作品审美质量相同。
