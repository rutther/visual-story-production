# 从真实失败中提取的通用诊断

这些条目来自制作日志和用户反馈的归纳；“技术修好”不代表相同骨架后来被用户认可。

| 症状 | 错误判断 | 更好的行动 | 验证证据 |
|---|---|---|---|
| 五种方案看起来一样 | 再改色、颗粒和字体 | 用同一内容比较照片规模、文字位置、明暗、字号层级 | 并排真实预览，说明骨架差异 |
| 长稿被压成新短稿 | 原时长比作者内容更重要 | 保留定稿，依据实际音频重建时长；关键冲突才询问 | 文本版本、段落覆盖、声画范围 |
| 地图没有山口感 | 平面海岸图上加更多点 | 区域定位→真实地形→有依据的方向→身份保持 | 数据来源与精度、实际中间视窗 |
| 人物移动仍像劣质PPT | FLIP正确就高级 | 先判断变化的是关系还是人物位置；固定身份、让关系改变 | 内容语义与连续画面，而非库调用成功 |
| 引语后只剩字幕 | 引语专项通过即全片通过 | 给前缀、引语、过渡、后续叙述分别安排内容 | 全段各状态与边界观察 |
| 名字配错照片 | 采访页主图就是受访者 | 核对身份、机构与实际图；无图用中性标识 | 文件页与原图身份 |
| 界面有文本，画面空白 | DOM文字非空即可 | 检查clip-path/祖先层和实际像素 | 同时点原生画面 |
| 正反定位不一致 | 整个渲染器坏了 | 差异包围框定位到图片、文字或状态；逐一验证原因 | 同版本同时间差异图与范围 |
| 头像飞走或地名跑顶部 | 通用入场动画可用于一切 | 世界定位父层与入场子层分开，保留原变换 | 地图内实际位置与中间状态 |
| 所有段落都先淡入 | 换更多随机转场 | 从变化语义选择揭示、比较、迁移、拆分、聚焦 | 段落信息增长和焦点接力 |
| 片子紧张却带立场滤镜 | 暗化等于专业战争片 | 以事件节奏和空间变化制造张力，统一对象视觉待遇 | 同类主体的色调、裁切、标签规则 |
| 窗口计时前进就记“看完” | 播放成功等于观察成功 | 如实记录采样或连续观察能力与范围 | 原始观察记录，未验证项保留 |
| 对话结束后无法继续 | 大段总结足够 | 保存目标、入口、版本、证据、活跃作业与下一动作 | 新目录/新会话按状态能找到实际文件 |

这些是诊断候选，不是自动修复规则。先确认当前症状与原因一致，再迁移方法。
